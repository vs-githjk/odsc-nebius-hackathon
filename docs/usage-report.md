## Why these services

Token Factory Qwen chat supplies structured intake, fingerprints, query plans and typed evidence questions. Qwen embeddings support near-duplicate clustering and possible-number variants. Code applies the matching rules and decides the ending. Tavily search discovers candidate pages in date windows; extract reads their text. Wayback and publication registries supply independent date evidence. The rows above show which calls actually occur in this saved set; an unused stage is not counted as measured.
