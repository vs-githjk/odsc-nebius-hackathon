# Where Patient Zero is wrong

This page lists every way we know Patient Zero can give a wrong or weaker answer: what goes wrong, an example you can run, the rule that should catch it, whether it is caught today, and who owns the fix. Nothing here is softened. If you find a failure that isn't listed, please open an issue.

Every open row that names a test is pinned in [packages/pz/test/limits.test.ts](../packages/pz/test/limits.test.ts) as the engine behaves **today**. Those tests pass while the gap is open. When a gap is closed, its test fails on purpose, and the PR that closes it has to flip the test and update the row here, so this page can't drift from the code.

## The biggest one first

**The first live dev run found no earliest page.** On Nov 17 the first live E2 run (main 940cd17, 17 recordings in [eval/dev-traces/](../eval/dev-traces/), [#194](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/194)) scored: false origins 1, target cited 1/11, earliest 0 of 11 (0 Pass, 0 Partial), cold stops 3/9, 17 of 20 claims scored ([#164](https://github.com/vs-githjk/odsc-nebius-hackathon/issues/164)). That is before the fixes on [#192](https://github.com/vs-githjk/odsc-nebius-hackathon/issues/192), and it replaces nothing below: the rows come from tests and planted cases, and the live causes are listed under "Measured so far". The SAMPLE traces in [fixtures/traces/](../fixtures/traces/) and the spike traces in [spike/traces/](../spike/traces/) are still invented or historical, and `make judge` and `make replay` say so on screen.

| L10 | **The independent-roots count can run high.** A group of copies with no verified link to anything earlier counts as its own root, even when it just didn't cite its source. | L15 | **A scholarly registry's date is trusted like the page's own metadata.** For pages it knows by URL, dating takes the publication date from NCBI esummary (PubMed, PMC) or Crossref (DOI links), with the same trust and the same archive cap as a meta tag. | L16 | **A trail can stop before it reaches the origin, at a cap.** The walk stops stepping back after `caps.depth` 8 steps back in time (F7, [#203](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/203): a step is a round whose search window moved earlier), and starts no new round once `caps.ms` (300 s) has passed. Either way the trace ends PARTIAL, "cap hit: depth" or "cap hit: ms", and the card is still written. A trail that keeps stepping back, like dev-05 "It takes 21 days to form a habit", can hit one before it goes cold or reaches its origin. A round already running finishes, so the walk can overrun the time cap by one round; [#212](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/212) (in review) stops new rounds at 70% of `caps.ms` instead, so the card has time. A round that only follows citations and finds nothing earlier is not a step: after 2 such rounds the trail ends cold, not PARTIAL. | test L16; [packages/pz/rules/rules.json](../packages/pz/rules/rules.json) `caps` | None: a cap is a budget, not a check. PARTIAL never names an origin, and the card says it stopped. | **No**. It is labelled, not avoided. | Rishit (F7, #203; time reserve, #212) |
| L17 | **A number right before a unit of measure is not the claim's count, but only for the units on the list.** "six 8 oz glasses of water" no longer states "eight glasses of water" ([#216](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/216), dev-04 on the second live run): the 8 measures the glass, and the count is six. It still misses units off the list: "in", "m" and "pounds" are left out on purpose, because they also mean "inside", "million" and money. Cups, pints, quarts, gallons and tablespoons aren't on it either, so "six 8 pound bags" or "two 8 gallon drums" can still pass as "8". The rule is off when the claim itself is counted in a measure ("64 ounces of water"). | test L17; [packages/pz/src/rules/numbers.ts](../packages/pz/src/rules/numbers.ts) `MEASURE_AFTER` | The typed `same_claim` question. On dev-04 it said yes at p 0.62, so only code stopped it. | **Partly**. Only the listed units. | Anoop (number rules) |
| L18 | **A page that presents the claim as already said is never the origin, but only for the wordings on the list.** "the seemingly ubiquitous admonition to drink at least eight 8-oz glasses" ends the page's chance to be the origin ([#225](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/225), dev-04 on the third live run, PubMed 12376390). The cues are `rules.json` `priorUseCues`: an admonition or adage, "commonly said", "the popular belief", "you've probably heard", "it is often said". Other wordings still pass: "you may have read that", "many people think", "a claim doing the rounds". The other way, a real origin whose own sentence uses a cue about something else ends cold instead of naming its origin. | test L18; [packages/pz/rules/rules.json](../packages/pz/rules/rules.json) `priorUseCues` | The typed `same_claim` question, which does not ask whether a page repeats the claim or makes it. | **Partly**. Only the listed wordings. | Anoop with XO (#225) |

## Measured so far, and not yet

These sections get filled from real runs, misses included, in the PR that commits each run.

- **Top causes from the first live dev run (T54, #112):** from XO's replay of the 17 recordings ([#192](https://github.com/vs-githjk/odsc-nebius-hackathon/issues/192)). (1) A page where `same_claim` said a confident "no" can still become the earliest page, and the next searches then end before the true origin: 8 claims (dev-02, 04, 06, 09, 10, 11, 18, 20). (2) Pages that got a `same_claim` yes were dated years late, because a DOI page was not sent to Crossref and in-page dates were read after Wayback: dev-09, dev-11, dev-14. (3) The only false origin, dev-13: its earliest page names an earlier print source in words ("In the November/December 2009 issue of World Watch"), and code counts only links as an earlier citation. Fixes are on #192, each with a replay re-score.
- **Gallery misses (T92, #159):** the answers were committed before any trace ([#168](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/168)). The traces aren't run yet. Every MISS and PARTIAL goes here.
- **Rematch losses (T93, #160):** the protocol and the draw are in [#171](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/171), but nothing has been run or graded. Every claim where a rival did better goes here.
- **Held-out misses (T67, #125):** the held-out run isn't done. Every miss goes here, as it is.
