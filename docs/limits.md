# Where Patient Zero is wrong

This page lists every way we know Patient Zero can give a wrong or weaker answer: what goes wrong, an example you can run, the rule that should catch it, whether it is caught today, and who owns the fix. Nothing here is softened. If you find a failure that isn't listed, please open an issue.

Every open row marked "test" is pinned in [packages/pz/test/limits.test.ts](../packages/pz/test/limits.test.ts) as the engine behaves **today**. Those tests pass while the gap is open. When a gap is closed, its test fails on purpose, and the PR that closes it has to flip the test and update the row here, so this page can't drift from the code.

## The biggest one first

**No real trace is committed yet.** As of Nov 16, every trace in the repo is a SAMPLE written for the tests ([fixtures/traces/](../fixtures/traces/)) or a historical spike trace ([spike/traces/](../spike/traces/)). `make judge` and `make replay` say so on screen. The first live dev run, the five reviewed default traces (#131) and the gallery (#159) will replace them. Until then, nothing on this page has been measured on real pages. The rows below come from tests and planted cases.

## Known failures

| # | What goes wrong | Example | The rule that should catch it | Caught today? | Owner |
|---|---|---|---|---|---|
| L1 | **A fake early date in a page's own metadata is trusted.** A page that says it was published in 1998, first archived in 2022, becomes the earliest page. With a fooled model, it can end as the origin. | test L1 | Dating caps a metadata date with the first archive capture, but only when the capture is the *earlier* of the two. A metadata date years before the first capture should be flagged. | **No** | Rohan (dating, #79) |
| L2 | **With the Wayback Machine down, dates are not capped at all.** Every date is then the page's own metadata, so L1 gets easier. | test L2 | None yet. The card does say "page metadata" next to such a date. | **No**. It's labelled, not blocked. | Rohan (dating) |
| L3 | **The claim's number used as a count passes the number rules.** "In 2015 Harbor Zoo had 14 penguins, and the penguins nap often" carries 14 and "penguins" in one clause. | test L3; also the second gap in [traps/README.md](../traps/README.md) | The typed `same_claim` question. It needs a model and a confident "no". | **Partly**. Only with a model, and only if the model says no. | Anoop (number rules T4b, T36). It needs an E2 re-measure, not a quick tweak. |
| L4 | **A copy that renames the subject is never matched.** "Harbor Zoo birds nap 14 times a day" is missed for a claim about penguins, so a renamed copy is never found and never counted. | test L4 | None. The number rules, and the embedding gate in #170, both need the claim's subject word. | **No** | Anoop |
| L5 | **A quote claim only matches its exact words.** A paraphrased quote, such as "repeating the same thing and hoping for a new result", is missed, so the trail can end early. | test L5 | None. Phrase claims (T53) match the phrase verbatim, or a declared range form. | **No** | Anoop (T53) |
| L6 | **The confidence cutoff for typed answers isn't set.** With `confidenceThreshold` null, any page type other than "unsure" counts, however low its probability, and any `same_claim` yes with a known probability counts. | test L6; [packages/pz/rules/rules.json](../packages/pz/rules/rules.json) | T48 (#99) sets the cutoff on E2 dev traces. | **No**. It waits on the live dev run. | Anoop (#99) |
| L7 | **Origins off the open web can't be found.** Print, paywalled, login-only and never-archived pages, and PDFs the extractor can't read, are out of reach. A claim from a 1960 book, such as dev-05 "It takes 21 days to form a habit" in [eval/dev-claims.json](../eval/dev-claims.json), can only end cold. | Every trace's scope note: "Web pages only; print and paywalled origins are out of scope. Earliest source we found, not proof of first use." | By design, the trail goes cold and isn't sent to a later web page. | **Yes, as a cold ending**. It never names the print origin. | Not a bug; it's the scope. |
| L8 | **The earliest page we found may not be the first.** Search only returns what it indexes. An earlier page that search never returns stays invisible. | [fixtures/traces/sample-rich.json](../fixtures/traces/sample-rich.json): the card says "It stopped before searching further back." | Decision table row 6 needs earlier-window searches before naming an origin. Every card says "earliest source we found". | **Partly**. The wording is honest, but the coverage gap is real. | Not a bug; it's search coverage. |
| L9 | **Instructions planted on a page can steer the model.** On main today, nothing checks for them. | Cases 11 to 13 and 17 to 24 in [#156](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/156) | #156 scans the whole page against a pattern list: 0 of 24 planted pages ended as the origin. A new wording can still get past a pattern list. | **Not on main**. With #156, only the wordings the list knows are caught. | Anoop (#156) |
| L10 | **The independent-roots count can run high.** A group of copies with no verified link to anything earlier counts as its own root, even when it just didn't cite its source. Until embeddings are on, a reworded copy also starts its own group. | [#167](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/167) (the count) and [#170](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/170) (embeddings) | Embeddings merge reworded copies (#170). There is no fix yet for an uncited copy. | **Partly**, once #170 is wired in | Anoop (#167, #170) |
| L11 | **Two similarity cutoffs are placeholders.** `clusterSimilarityThreshold` (0.9) and `otherNumberSimilarity` (0.8, in #170) haven't been measured on real vectors. | [packages/pz/rules/rules.json](../packages/pz/rules/rules.json) | `eval/drift/measure.ts` in #170, run live on the 107 labelled E2 sentences. | **No**. It waits on that live run. | Anoop (#164) |
| L12 | **One model answers every typed question.** If it is confidently wrong about a page type, only the other code checks stand between it and an origin, and L1 and L3 show two cases where they don't. | The fooled-model cases in [#156](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/156) | A second Token Factory model on `same_claim` (#138). | **No** | Anoop (#138) |
