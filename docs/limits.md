# Where Patient Zero is wrong

This page lists every way we know Patient Zero can give a wrong or weaker answer: what goes wrong, an example you can run, the rule that should catch it, whether it is caught today, and who owns the fix. Nothing here is softened. If you find a failure that isn't listed, please open an issue.

Every open row that names a test is pinned in [packages/pz/test/limits.test.ts](../packages/pz/test/limits.test.ts) as the engine behaves **today**. Those tests pass while the gap is open. When a gap is closed, its test fails on purpose, and the PR that closes it has to flip the test and update the row here, so this page can't drift from the code.

**No real trace is committed yet.** As of Nov 16, every trace in the repo is a SAMPLE written for the tests ([fixtures/traces/](../fixtures/traces/)) or a historical spike trace ([spike/traces/](../spike/traces/)). `make judge` and `make replay` say so on screen. ## Known failures

| # | What goes wrong | Example | The rule that should catch it | Caught today? | Owner |
|---|---|---|---|---|---|
| L1 | **A fake early date in a page's own metadata is trusted.** A page that says it was published in 1998, first archived in 2022, becomes the earliest page. With a fooled model, it can end as the origin. | test L1 | Dating caps a metadata date with the first archive capture, but only when the capture is the *earlier* of the two. A metadata date years before the first capture should be flagged. | **No** | Rohan (dating, #79) |
| L2 | **With the Wayback Machine down, dates are not capped at all.** Every date is then the page's own metadata, so a page dated after its first capture keeps the later date, and L1 gets easier. | test L2 (the same page, capped with the archive up and not with it down) | None yet. The card does say "page metadata" next to such a date. | **No**. It's labelled, not blocked. | Rohan (dating) |
| L3 | **The claim's number used as a count passes the number rules.** "In 2015 Harbor Zoo had 14 penguins, and the penguins nap often" carries 14 and "penguins" in one clause. | test L3 | The typed `same_claim` question. It needs a model and a confident "no". | **Partly**. Only with a model, and only if the model says no. | Anoop (number rules T4b, T36). It needs an E2 re-measure, not a quick tweak. |
| L4 | **A copy that renames the subject is never matched.** "Harbor Zoo birds nap 14 times a day" is missed for a claim about penguins, so a renamed copy is never found and never counted. | test L4 | None. The number rules, and the embedding gate in #170, both need the claim's subject word. | **No** | Anoop |
| L5 | **A quote claim only matches its exact words.** A paraphrased quote, such as "repeating the same thing and hoping for a new result", is missed, so the trail can end early. | test L5 | None. Phrase claims (T53) match the phrase verbatim, or a declared range form. | **No** | Anoop (T53) |
| L6 | **The confidence cutoff for typed answers isn't set.** With `confidenceThreshold` null, any page type other than "unsure" counts, however low its probability, and any `same_claim` yes with a known probability counts. | test L6; [packages/pz/rules/rules.json](../packages/pz/rules/rules.json) | T48 (#99) sets the cutoff on E2 dev traces. | **No**. It waits on the live dev run. | Anoop (#99) |
| L7 | **Origins off the open web can't be found.** Print, paywalled, login-only and never-archived pages, and PDFs the extractor can't read, are out of reach. A claim from a 1960 book, such as dev-05 "It takes 21 days to form a habit" in [eval/dev-claims.json](../eval/dev-claims.json), can only end cold. | Every trace's scope note: "Web pages only; print and paywalled origins are out of scope. Earliest source we found, not proof of first use." | By design, the trail goes cold and isn't sent to a later web page. | **Yes, as a cold ending**. It never names the print origin. | Not a bug; it's the scope. |
| L8 | **The earliest page we found may not be the first.** Search only returns what it indexes. An earlier page that search never returns stays invisible. | [fixtures/traces/sample-rich.json](../fixtures/traces/sample-rich.json): the card says "It stopped before searching further back." | Decision table row 6 needs earlier-window searches before naming an origin. Every card says "earliest source we found". | **Partly**. The wording is honest, but the coverage gap is real. | Not a bug; it's search coverage. |
| L9 | **Instructions planted on a page can steer the model.** The page check is a pattern list, so a new wording gets past it. | test L9; the adversarial cases in [traps/adversarial/](../traps/adversarial/) | The whole page is scanned against `injectionPatterns` (#156): 0 of 24 planted pages ended as the origin. | **Partly**. Only the wordings the list knows are caught. | Anoop (#156) |
| L10 | **The independent-roots count can run high.** A group of copies with no verified link to anything earlier counts as its own root, even when it just didn't cite its source. Until embeddings are on, a reworded copy also starts its own group. | [#167](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/167) (the count) and [#170](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/170) (embeddings) | Embeddings merge reworded copies (#170). There is no fix yet for an uncited copy. | **Partly**, once #170 is wired in | Anoop (#167, #170) |
| L11 | **Few reworded copies are grouped.** At `clusterSimilarityThreshold` 0.9, XO's live E2 measure found 0 of 4315 different-claim pairs wrongly merged, but only 23 of 635 same-claim pairs merged, so most reworded copies still start their own group (see L10). **The "possible variant" line is wrong more often than right.** `otherNumberSimilarity` was set to 0.75 on E2 (precision 0.82, recall 0.64). Checked once on E3 at that value, untuned, it gave precision 0.37 and recall 0.58: 14 true hits, 24 false hits, 10 missed ([#185](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/185)). A listed page is never a node, so it can't change an ending, and the card calls it a possible variant, never "became". | test L11; [eval/drift/README.md](../eval/drift/README.md) | A lower cluster cutoff, measured on E2 the same way. | **No** | Anoop (#164) |
| L12 | **One model answers every typed question.** If it is confidently wrong about a page type, only the other code checks stand between it and an origin, and L1 and L3 show two cases where they don't. | test L12; the fooled-model cases in [traps/adversarial/](../traps/adversarial/) | A second model family on `same_claim` is built ([#178](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/178)) but stays off: measured on E2, it lost 23 of 60 true hits and removed no false ones. | **No** | Anoop (#138) |
| L13 | **A negation in new wording passes code.** "Researchers checked this, and it is simply untrue that penguins nap 14 times a day" isn't caught: `negationPrefixes` matches its listed words only. | test L13; 3 `negate-paraphrase` pipeline traps (spike claims 2, 3 and 5) in [#173](https://github.com/vs-githjk/odsc-nebius-hackathon/pull/173), which end as the origin under a model that says "same claim" (the dry-run copy tests nothing: that source ends cold before any mutation) | The typed `same_claim` question. It needs a model and a confident "no". Adding the trap's words to the list would only tune it to the trap. | **Partly**. Only with a model, and only if the model says no. | Anoop |
| L14 | **On live runs, only the circular cold ending can show yet.** The print and unsourced endings need the boundary question, asked by `withBoundaries` ([packages/pz/src/engine/boundary.ts](../packages/pz/src/engine/boundary.ts)), and nothing in the pipeline calls it yet. A cold trail that ends at a book or at an unsourced wiki page reads as a plain cold ending. | test L14 | The live pipeline adapter (#130) calls `withBoundaries` after the walk and before the card. `runTrace` holds no model client, so the call belongs in the adapter. | **No**. It waits on #130. | Anoop with XO (#87, #130) |
